## Routing

| Need | Route |
| --- | --- |
| Defect or documentation gap | Open a sanitized issue in this repository |
| Proposed Ring-0 change | Open a pull request with the evidence required by [CONTRIBUTING.md](CONTRIBUTING.md) |
| First apply or state recovery | Follow [docs/first-apply.md](docs/first-apply.md) or [docs/state-recovery.md](docs/state-recovery.md) |
| Break-glass event | Follow [docs/break-glass.md](docs/break-glass.md) and the approved incident process |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); never open an issue |
| Access or GitHub governance | Use the owning process in `mindclade/github-config` |
| Contractual customer support | Use the channel and service terms in the applicable agreement |

GitHub issues do not carry an SLA. This repository is not a general cloud-help
desk and must not receive credentials, private keys, Terraform state or plans,
customer data, model weights, restricted biological content, or incident
evidence. Use sanitized resource identifiers and evidence digests.

The applicable customer agreement or incident-response process controls if it
conflicts with this routing guide.
